Workspace 1

workspaceEvents

workspaceEvents(workspaceId: ID!): String!

Subscribe to all real-time events for a workspace. Returns events as JSON strings — the client parses the type field to determine the event kind.

The subscriber's membership is checked when the subscription starts. Afterwards their guest status follows their MemberRoleChanged events, and the stream ends after their MemberLeft. When the subscriber falls behind and events are dropped, their membership and role are loaded again before any further event is delivered; the stream ends when that load fails, including when they are no longer a member.

Relay 1

relayStream

relayStream(after: ID): String!

Host events queued for the session's device on this relay, above after (the device's cursor when omitted), then live ones, as JSON strings: {"type":"RelayItem","id","hostServerId","workspaceId","envelope"}, and the DmRequestReceived, QueueOverflow and RevocationAcked notices. While one is open the hosts of the user's workspaces see them online.
