CommandResultStatusenum

ValueDescription
SUCCESS
ERROR
CONFIRMATION_REQUIRED

The command needs a confirmation and the call carried no matching proof. That is the case for a dangerous or RESTRICTED command, and for a MUTATING one an AGENT or PLUGIN initiator runs. confirmationRequired on the result carries the challenge: show it to the user, then re-submit with confirmation: { inBandToken: { token, argsHash } }.

Used by CommandResult, PipeStageResult

CommandSensitivityenum

How much a command can affect. It decides whether a call needs a confirmation proof and is recorded in the audit log; clients use it to cap an agent's mutating calls.

ValueDescription
SAFE

Read-only, no user-visible side effects.

SENSITIVE

Tracked in audit but low blast radius.

MUTATING

Mutates durable state; counts against agent mutating-call cap.

RESTRICTED

High-blast-radius admin/destructive; always requires confirmation.

Used by Command, CreateMacroInput, MacroDef, UpdateMacroInput
