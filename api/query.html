Command 2

commands

commands(surface: CommandSurface, commandContext: CommandContextInput): [Command!]!

The commands the caller may run on surface (default PALETTE), sorted by id.

A command the server runs is listed only when commandContext.workspaceId names a workspace the caller is a member of, their role there may run it, and they hold each of its required capabilities. The commands the client runs itself are listed in every context. A listed command is one executeCommand runs for the caller in that context, apart from a confirmation, a timeout in force and the arguments given. Naming the direct space makes the caller a guest of it.

AI lists only the AI-callable commands, plus the caller's AI-callable macros of the workspace, and fails with FEATURE_DISABLED while the AI command surface is off.

commandDiscover

commandDiscover( intentPhrase: String limit: Int workspaceId: ID ): [Command!]!

The AI-callable commands the caller may run, for an AI agent to discover its tools.

Filtered as commands filters: a command the server runs is listed only when workspaceId names a workspace the caller is a member of, their role there may run it, and they hold each of its required capabilities; the commands the client runs itself are always listed. A listed command is one executeCommand runs for the caller in that workspace, apart from a confirmation, a timeout in force and the arguments given.

With intentPhrase the commands are ranked by how well the phrase matches their intent samples, title and natural-language description. limit defaults to 50 and is capped at 100. workspaceId scopes the list to one workspace, including its AI-callable macros.

Limited to 5 calls per 60-second sliding window per user; more fail with RATE_LIMITED. Fails with FEATURE_DISABLED while the AI command surface is off.

Search 1

searchMessages

searchMessages(input: SearchMessagesInput!): SearchResultPage!

Full-text search over the messages of a workspace the caller can read. input.query accepts free text plus the operators from:@user, in:#channel, has:link, has:attachment, after:YYYY-MM-DD and before:YYYY-MM-DD.

Results are cursor-paginated by recency, (sentAt, id), like every other message list. They are not ordered by rank: a relevance score is neither unique nor stable, so paging by it would skip or repeat results. rank and headline come with every item for display or a sort within the page.
